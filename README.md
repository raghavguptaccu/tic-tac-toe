# Tic-Tac-Toe in Java

A simple console-based Tic-Tac-Toe game made using Java.
This was a small project I made to practice Java and get more comfortable with things like classes, methods, arrays, loops, and handling user input.

## How it works

The game is played between two players:
* Player `X`
* Player `O`

The board has 9 positions:

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

Players take turns entering the number of the position where they want to place their symbol.
The first player to get three of their symbols in a row/column/diagonal wins
